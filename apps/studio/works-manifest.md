# Works Manifest

Editable lineup of the `opusWork` documents on the portfolio (Sanity `dn2lfgdt` / `production`).
Nothing in Sanity changes until you hand this file back and I apply it.

## How to edit

- **Positions / ordering**: line order is the order. Drag lines up or down (alt+↓ / alt+↑ in VS Code). Nothing to renumber.
- **Move between lists**: cut the line and paste it into the other section. The `selected` flag in Sanity follows the section.
- **Remove**: write `remove` at the end of a line, or move the line into the `## Remove` section. That deletes the document from Sanity permanently. Deleting a line outright is a no-op: the work stays in Sanity and sinks to the end of its list.
- **Preview**: card layout variant — `preview 1` / `2` full-width card, `3` last cell full-width, `4` single-column grid. Drop the `preview N` part to leave it untouched.
- **Title / slug**: read-only here. Lines match by the backticked slug, so leave that bit as-is; rename content in Sanity Studio (docs live there as "Opus Work").
